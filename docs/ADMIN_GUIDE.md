# 관리자용 1페이지 검증 가이드 — 60초 AI 돌봄보고

## 0. 먼저 체험해보고 싶다면 — 데모 모드
```
https://(배포 주소)/admin?demo=1
```
비밀번호는 **demo1234**입니다(화면에도 안내됩니다). `/care?demo=1`에서 만든
데모 보고가 바로 여기 반영됩니다. 우측 상단 "피칭 화면" 버튼으로
`/admin/presentation?demo=1`(투자자용 요약 화면)도 확인할 수 있습니다.
데모 데이터는 실제 실증 통계와 절대 합산되지 않습니다.

## 1. 접속·로그인 (실제 실증)
```
https://(배포 주소)/admin
```
설정해 둔 관리자 비밀번호로 로그인합니다. (비밀번호는 코드에 없고 서버 환경변수
`CARE_PILOT_ADMIN_PASSWORD_HASH`로만 관리됩니다 — 발급 방법은 `.env.local.example`
참고)

## 2. 대시보드
- 맨 위 **핵심지표**: "관리자가 추가 질문 없이 바로 이해한 보고율" (분자/분모 함께
  표시, 예: 14건 중 10건, 71.4%). 관리자 2단계 평가가 끝난 보고만 반영됩니다.
- **오늘 참여 현황**, **목표(9명×10회=90건) 대비 진행률**.
- **AI 적용 전후 비교**: 원문만 봤을 때 vs AI 보고문을 봤을 때의 "바로 판단 가능"
  비율 차이(%p), 추가질문 필요율, 필수정보 충실도 평균 변화, 실제 전화/문자
  확인 발생률.
- **참여현황표**: C01~C09 × 날짜. 초록 = 기본보고 제출, 청록 숫자 = 추가보고
  건수, 회색 = 미제출. 8초마다 자동 갱신되므로 새로고침하지 않아도 됩니다.

## 3. 보고 평가 (가장 중요한 작업)
**보고 목록** 탭 → 보고 클릭 → 아래 순서로 평가합니다.

1. **1단계(원문 평가)**: 화면에는 **최초 원문만** 보입니다. AI 결과를 미리 보지
   말고, "원문만으로 바로 판단 가능한가", "추가 질문이 필요한가",
   "필수정보 충실도(1~5)"를 평가한 뒤 **저장**하세요. 저장해야만 2단계가 열립니다.
2. **2단계(AI 보고 평가)**: AI 추가 질문/답변, AI 생성보고, 요양보호사가 최종
   수정한 보고문이 나란히 보입니다. "최종보고만으로 바로 이해 가능한가",
   "실제 전화/문자 확인 발생 여부", "업무 유용성(1~5)", "사실과 다른 내용
   포함 여부", 처리상태를 평가하고 저장하세요.
- 재평가하면 이전 값이 자동으로 이력에 보관됩니다.
- **삭제**가 필요하면(오작성 등) 사유를 입력하고 삭제하세요. 실제로 지워지지
  않고 "삭제됨" 표시만 되며(소프트 삭제) 목록·통계에서 제외됩니다.

## 4. 참여자 관리
**참여자 관리** 탭에서 C01~C09의 PIN을 초기화할 수 있습니다. 새 PIN은 화면에
**한 번만** 표시되니 즉시 오프라인(전화/문자/메모)으로 해당 요양보호사에게
전달하세요. 실제 이름과 코드를 연결하는 대응표는 이 시스템이 아니라 관리자가
별도로 오프라인 문서로 보관합니다.

## 5. CSV 다운로드
**보고 목록** 탭 상단의 **요약 CSV**(민감한 원문 제외, 지표 중심) / **전체
CSV**(원문·AI보고 포함)를 눌러 내려받습니다. 투자자 피칭·실증 리포트 작성에
사용하세요.

## 주의사항
- 관리자 화면 접근에는 실제 로그인이 필요합니다(URL만 안다고 들어갈 수 없음).
- 표본이 적을 때는 비율만 보지 말고 항상 "OO건 중 OO건" 분모를 함께 확인하세요.
- 이 화면도 의료 진단을 제공하지 않습니다.
