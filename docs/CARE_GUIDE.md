# 요양보호사용 1페이지 사용법 — 60초 AI 돌봄보고

## 0. 먼저 체험해보고 싶다면 — 데모 모드
Supabase·Gemini 연결 없이 지금 바로 전체 흐름을 체험할 수 있습니다.

```
https://(배포 주소)/care?demo=1
```
참여자 코드는 C01~C09 아무거나, PIN은 **1234**로 로그인하세요. 화면
상단에 "DEMO DATA" 배지가 뜨고, 입력한 내용은 이 브라우저에만 저장됩니다
("데모 초기화" 버튼으로 언제든 리셋). 실제 실증 데이터와는 완전히 분리되어
있습니다.

## 1. 접속 (실제 실증)
스마트폰 브라우저에서 아래 주소로 들어갑니다.

```
https://(배포 주소)/care
```

## 2. 로그인 (최초 1회)
- **참여자 코드**(예: C01)와 **PIN**(숫자 4자리)을 입력합니다.
- 코드와 PIN은 센터 관리자에게 문의하세요.
- 한 번 로그인하면 이 기기에서 **2주간** 다시 로그인하지 않아도 됩니다.

## 3. 오늘 돌봄보고 작성
1. 로그인하면 홈 화면에 **오늘 돌봄 대상**(내게 배정된 수급자)이 바로 보입니다 —
   따로 고를 필요 없습니다(배정된 대상자가 2명 이상이면 "대상자 변경"으로 바꿀 수
   있습니다).
2. **"이야기 시작"**(원형 버튼)을 누르면 곧바로 음성 인식이 시작됩니다. 타이핑을
   원하면 그 아래 **"글로 입력하기"**를 누르세요 — 음성이든 글이든 이어지는 흐름은
   같습니다. (이미 오늘 기본보고를 냈다면 이 버튼 대신 **"추가 상태변화
   기록하기"**가 나타나 특이사항만 추가로 보고할 수 있습니다.)
3. 오늘 관찰한 내용을 말하거나 입력합니다. **음성 인식이 안 되거나 틀리게
   인식돼도 괜찮습니다** — 화면 아래 입력창에 언제든 직접 타이핑하거나 고칠 수
   있습니다.
4. 특이사항이 없으면 "오늘은 특별히 달라진 점이 없었어요"처럼 그대로 말해도
   됩니다.
5. **"이 내용으로 보고하기"**를 누릅니다.

## 4. AI 추가 질문 (있을 수도, 없을 수도 있음)
- AI가 부족한 정보를 물으면 화면에 **질문이 하나씩만** 나옵니다. 보통 바로 누를 수
  있는 **선택지 버튼**이 함께 나오고, 상황에 안 맞으면 "다른 내용 말하기"로 직접
  입력할 수 있습니다.
- 질문은 **최대 3번**까지만 나옵니다. 더 답할 내용이 없으면 "여기까지
  말씀드릴게요"를 눌러 바로 마무리할 수 있습니다.

## 5. 보고 내용 확인 · 제출
- AI가 만든 보고문(관찰한 돌봄 상황 / 현장에서 한 조치 / 현재 상태 / 센터 확인사항 /
  요양보호사 상황·지원 요청)이 나옵니다. 틀린 부분이 있으면 직접 고친 뒤
  **"이대로 센터에 보내기"**를 누르세요.
- "센터에 보고되었습니다."가 뜨면 완료입니다. 홈 화면에는 "오늘 돌봄기록을
  남겼어요"가 표시되고, 그날 남긴 기록은 **"내가 남긴 돌봄기록"**에서 다시 볼 수
  있습니다.

- **실명·주소·전화번호 등 개인정보는 말하거나 입력하지 마세요.**

  위험이 의심되면 AI 답변을 기다리지 말고 화면 상단의 **119 전화** 또는
  **센터 전화** 버튼을 바로 누르세요.
- 인터넷이 잠깐 끊겨도 입력한 내용은 사라지지 않습니다. 다시 접속하면 이어서
  작성할 수 있습니다.
- 목표는 **하루 1회(기본보고)**입니다. 특이사항이 있으면 그때그때 추가보고도
  남겨 주세요.
